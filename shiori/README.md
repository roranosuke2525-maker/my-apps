# しおり（読書ノート・PWA）

付箋を貼ったページの文と Kindle のハイライトを、Notion の **読書メモ_DB**（本）と **DB_読書ハイライト** に集める読書アプリ。
読みながら出てきた舞台・植物・人物の距離感・言葉は **DB_読書辞典** に本ごとにためる。
読み終えたら、感想を読書メーターへ、ハイライトを NotebookLM へ渡す。ホーム画面に追加するとアプリのように使える。

```
iPhone（ホーム画面のアプリ） ──合言葉──▶ Cloudflare Worker ──トークン──▶ Notion API
                                          （画面の配信＋中継）
```

- Notion のトークンは **Cloudflare 側の秘密の値にだけ**置く。スマホ・ブラウザ・社内PCには残らない
- アプリを開くには合言葉（APP_KEY）が要る。合言葉は端末のブラウザにだけ保存される
- AI は使わない。写真の文字は iPhone の「テキスト認識」でコピーして貼る
- Cloudflare Workers の無料枠で動く

## 画面

| 下のタブ | 中身 |
| --- | --- |
| 本棚 | 読んでいる／これから／読んだ／すべて。本を押すとシートで開く（ハイライトの一覧・メモ・手で足す・前の形のハイライト・NotebookLM に渡す）。「＋ 本を足す」で読書メモ_DB に1冊足す |
| 付箋のページ | 本を選び、テキスト認識でコピーしたページの文を貼って「文に分ける」。印刷の行の改行はつなぎ、数字だけの行はページ番号にする。大事な文を押してハイライトにし、メモを書いて保存。写真は見比べ用に横に出せる（保存しない） |
| Kindle | 「メモとハイライト」（read.amazon.co.jp/notebook）のコピー、または My Clippings.txt を貼って読み取る。書名から本を合わせ、登録済みのハイライトは外しておく |
| 辞典 | 本を選び、読みながら出てきた語を足す（語・種別・初めて出たページ・説明・メモ）。種別は 📍舞台／🌿植物／👥人物・距離感／🍽食・道具／📖言葉／✦その他。種別ごとに調べるリンク（舞台→地図、植物→画像、言葉→辞書。人物はネタバレよけで出さない）。「p.○まで」を入れると、それより後のページの語を隠す。説明が空の語は、チャットで「読書辞典を埋めて」と頼むと Claude が Notion に書き足す |
| 読み終えた | 評価（★）・読了日・感想（255文字まで）を保存して読了に。感想をコピーして読書メーターで本を探す。NotebookLM 用の文をコピー、またはファイルで保存（iPhone では共有シート） |

## 読む／書くもの

| つなぎ先 | 読む | 書く |
| --- | --- | --- |
| 読書メモ_DB | 全件（書籍名・著者名・出版社・ステータス・読了日・評価・感想・読書メーター・NotebookLM・表紙・ハイライトの数）と、著者名・出版社の選択肢 | 本の追加、ステータス・読了日・評価・感想・読書メーター・NotebookLM |
| DB_読書ハイライト | 開いた本に紐づく行 | 行の追加（引用・本・ページ・位置・出どころ・メモ・記録日。ページの文から足したときは本文に「ページの文」を残し、ハイライトの所に黄色を付ける）、メモ |
| DB_読書辞典 | 開いた本に紐づく語 | 語の追加（語・本・種別・ページ・説明・メモ・記録日）、直す、消す（Notion のゴミ箱へ。戻せる） |
| 前の形（本のページの下の子ページ） | タイトル（引用）と本文の文字・写真の有無（1冊20件まで） | なし |

- 書き換える前に、そのページが 読書メモ_DB／DB_読書ハイライト の行かを確かめる（ほかのページには触らない）
- 未読の本にハイライトを足すと、その本を「読中」にする
- 1回に足せるハイライトは40件（無料プランの Worker は1回の通信が50件まで）。Kindle の取り込みは画面が40件ずつに分けて送る
- 読書メーターと NotebookLM には外から書き込む仕組みが無いので、「コピー／ファイル＋開くリンク」までをアプリが受け持ち、済んだら印（チェック）を付ける

## セットアップ（PCのブラウザだけでできる）

### 1. Notion：インテグレーションを作る

1. https://www.notion.so/profile/integrations で「新しいインテグレーション」→ 種類：内部、名前：しおり
2. 機能は「コンテンツを読み取る」「コンテンツを更新」「コンテンツを挿入」だけON（コメント・ユーザー情報はOFF）
3. シークレット（`ntn_…`）をコピーしておく（Notionのページには貼らない）
4. Notion で **読書メモ_DB** を開き、右上「•••」→「接続」→「しおり」を追加
5. **DB_読書ハイライト** と **DB_読書辞典** にも同じく接続する（ME・データベースなどの親ページには接続しない）

### 2. Cloudflare：Worker を作る

1. https://dash.cloudflare.com にログイン（習慣チェックと同じアカウントでよい）
2. 「Workers & Pages」→「作成」→「Gitリポジトリをインポート」→ GitHub の `my-apps` を選ぶ
3. 設定
   - プロジェクト名：`shiori`
   - ルートディレクトリ：`shiori`
   - ビルドコマンド：空欄／デプロイコマンド：`npx wrangler deploy`
4. デプロイ後、Worker の「設定」→「変数とシークレット」で **シークレット**を2つ追加して再デプロイ
   - `NOTION_TOKEN`：手順1でコピーした `ntn_…`
   - `APP_KEY`：合言葉（16文字以上。パスワードマネージャーで作ると楽）
5. `https://shiori.<あなたのサブドメイン>.workers.dev` が表示されたら完了

以後、このフォルダを GitHub で更新すると自動で再デプロイされる。

> いま動いているもの：`https://shiori.roranosuke2525.workers.dev`（2026-10-27 に Claude のセッションから `npx wrangler deploy` で公開。Git の自動デプロイはつないでいないので、更新は同じく `npx wrangler deploy` で出す）

### 3. iPhone：ホーム画面に追加

1. Safari で上のURLを開き、合言葉を入れる
2. 共有ボタン →「ホーム画面に追加」

## よくあるエラー

| 表示 | 原因 |
| --- | --- |
| 合言葉が違います | APP_KEY と違う。もう一度入れ直す |
| インテグレーションが接続されていません | 手順1-4・1-5 の接続忘れ（辞典タブだけ出るときは DB_読書辞典 への接続忘れ） |
| Notion のトークンが正しくありません | NOTION_TOKEN の貼り間違い |
| Worker の設定が足りません | シークレット2つが未設定、または APP_KEY が16文字未満 |
| 前の形のハイライトが出ない | 子ページが読書メモ_DB の外にある（接続が届いていない） |

## 開発

```sh
npm install
npm test               # Worker（Notion は偽物に差し替え）と文字の読み取り（public/parse.js）のテスト
npx wrangler dev       # ローカルで起動（.dev.vars に NOTION_TOKEN と APP_KEY を書く）
python3 scripts/make-icons.py   # アイコンを作り直す
```

- `src/worker.js`：Notion API の中継（API バージョン 2025-09-03、データソース指定）。DB のIDは `wrangler.toml`
- `public/parse.js`：Kindle の貼り付け・ページの文の区切り・NotebookLM に渡す文（画面と Notion に依存しない）
- `public/`：画面（HTML/CSS/JS、サービスワーカー、アイコン）
