# しおり（読書ノート）

付箋を貼ったページの写真と Kindle のハイライトを、Notion の **読書メモ_DB**（本）と **DB_読書ハイライト** に集める読書アプリ（claude.ai のアーティファクト）。
読み終えたら、感想を読書メーターへ、ハイライトを NotebookLM へ渡す。

- 公開先：[しおり](https://claude.ai/artifact/LGKJ7DFxEtuWn2xtETzfNY)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバー・社内PCへの保存はない
- 写真の読み取りと感想の下書きは、見ている人の Claude（sample）に頼む

## 画面

| 下のタブ | 中身 |
| --- | --- |
| 本棚 | 読んでいる／これから／読んだ／すべて。本を押すとシートで開く（ハイライトの一覧・メモ・手で足す・前の形のハイライト・NotebookLM に渡す）。「＋ 本を足す」で読書メモ_DB に1冊足す |
| 付箋を撮る | 本を選んで写真を撮る・選ぶ（何枚でも）。Claude がページ全体を文字に起こし、付箋の先・線の引かれた行（なければ要になる文）に色を付ける。文を押して付け外し、メモを書いて保存 |
| Kindle | 「メモとハイライト」（read.amazon.co.jp/notebook）のコピー、または My Clippings.txt を貼って読み取る。書名から本を合わせ、登録済みのハイライトは外しておく。形が崩れているときは「AIで読み取る」 |
| 読み終えた | 評価（★）・読了日・感想（255文字まで、ハイライトから下書き）を保存して読了に。感想をコピーして読書メーターで本を探す。NotebookLM 用の文をファイル保存かコピー |

## 読む／書くもの

| つなぎ先 | 読む | 書く |
| --- | --- | --- |
| 読書メモ_DB | 全件（書籍名・著者名・出版社・ステータス・読了日・評価・感想・読書メーター・NotebookLM・表紙）と、著者名・出版社の選択肢 | 本の追加、読み込んだ本の ステータス・読了日・評価・感想・読書メーター・NotebookLM |
| DB_読書ハイライト | 開いた本に紐づく行 | 行の追加（引用・本・ページ・位置・出どころ・メモ・記録日。写真のときは本文に「ページの文」を残し、ハイライトの所に色を付ける）、読み込んだ行の メモ |
| 前の形（本のページの下の子ページ） | タイトル（引用）と本文の文字・写真の有無 | なし |

- 未読の本にハイライトを足すと、その本を「読中」にする
- 読書メーターと NotebookLM には外から書き込む仕組みが無いので、「コピー／ファイル保存＋開くリンク」までをアプリが受け持ち、済んだら印（チェック）を付ける
- 写真そのものは Notion に保存しない（文字にしたものだけを残す）

## 作り方

```sh
npm test                          # /api（src/mcp-api.js）と文字の読み取り（public/parse.js）を確かめる
node scripts/build-artifact.mjs   # dist/artifact.html を作る（公開は Claude に「アーティファクトを更新して」）
```

公開するときは capabilities に次を宣言する。

```json
{"mcp": {"servers": [{"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page", "notion-create-pages"]}]},
 "sample": {"images": true}, "downloads": true}
```
