今どこ ウィジェット

iPhone のホーム画面・ロック画面に「今日の残り・遅れ・まず これ」を出し、○ を押すと済み、→ を押すと明日にずらせます。無料アプリ Scriptable で動きます。

1. Scriptable を入れるApp Store で Scriptable を開く
2. スクリプトを取り込む（どちらか）
ファイルを保存して Scriptable で開く

コピーした場合：Scriptable を開き「＋」→ 貼り付け → 左上の名前を「今どこ」にして完了。

3. 一度実行して合言葉を入れる

Scriptable で「今どこ」を実行すると合言葉（アプリと同じ）を聞きます。この iPhone の Keychain にだけ保存されます。

4. ウィジェットを置く

ホーム画面を長押し →「＋」→ Scriptable → 大きさを選ぶ → 置いたウィジェットを長押し →「ウィジェットを編集」→ Script に「今どこ」。ロック画面も同じ手順（丸・四角・1行）。15分ごとに自動で更新されます。
