# 今どこ工場

Notion のタスク・診断・目標・すべてのDBを、**工場のフロア（部屋の間取り図）**で体系的に見て操作するアプリ（claude.ai のアーティファクト）。
タスクの「今どこ」（DB_タスク管理の計算式の6区分）が部屋、タスクが箱。別案集（下）の「工場」案を本番にしたもの。

- 公開先：[今どこ工場](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- スクロールなし。一覧・本文は左右スワイプで頁をめくる（1頁の件数は画面の高さから自動で決める）

## 画面

ホームは工場のフロア（真上から見た間取り図）。部屋＝今どこ、箱＝タスク。

| 部屋 | 今どこ・中身 | 動き |
| --- | --- | --- |
| 受入室 | 倉庫（INBOX）。パレットに箱 | |
| 仕分け室 | 次にやる。作業台に箱と作業員 | |
| 加工室 | 今日やる。機械・ランプ | 歯車が回る（遅れがあると遅くなる）／遅れは赤い箱・ランプ点滅・「遅れ」札 |
| 出荷場 | 済み（今日の分）。トラック | トラックがアイドリング |
| 予定倉庫 | 予定あり。棚と次の着手日 | |
| 保留室 | 待ち。黄黒の保留区画 | 回転灯が点滅 |
| AIラボ | AI。作業台とロボットアーム | 腕が動く |
| 組立室 | 進行中のプロジェクトの完成度バー | バーが伸びる |
| 管理室（入る） | 生産管理：診断（正常稼働／要改善・改善）、計器（出荷率・遅れ・在庫・自分の番）、生産の推移、作業日報（DB_運用ログ） | モニターに折れ線、計器と数字が伸びる |
| 営業室（入る） | 目標＝受注、紐づくプロジェクト＝製造ロット（ベルト上の箱の位置＝完成度） | 挑戦中の目標の旗がはためく |
| 資材倉庫（入る） | 🗄 データベース ページの節＝棚、DB＝品目。棚→品目→アンドン（行の一覧）→作業伝票（行の中身） | 棚の前をフォークリフトが行き来 |

- 中段の4部屋（受入→仕分け→加工→出荷）をベルトコンベアが通り、箱が流れる。上段との間の通路をフォークリフトが行き来する
- 部屋をタップすると下の **アンドン**（作業指示の電光板）にその部屋のタスク。管理室・営業室・資材倉庫は、その部屋へ寄っていくように拡大して中に入る
- 上の電光掲示（構内放送）：遅れ・出荷数・保留の最長・AIの自分の番・最新の診断・最新の作業日報が流れる
- アンドン：品種＝重さ（S小物・M中物・L大物・XL特大）、品名＝タスク名（長いと流れる）、納期・遅れ日数・滞留日数、ライン＝枠。行はパタパタと表示
- 作業伝票（タスク・行を開いたとき）：運ぶ先のボタン（加工室へ・予定倉庫（明日／週末）・保留室へ・寝かせる・資料室へ・AIラボへ・出荷）。箱が通路を通って部屋から部屋へ運ばれる。本文（スワイプでめくる・チェック項目の✓・トグル）、項目、書く（やることに足す／メモ／次の作業）
- 右上「✎」：新規入荷（受入室・仕分け室・加工室・予定倉庫（明日）のどこへ運び込むか選ぶ）

## 「今どこ」の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出し直す（ME の各ビューの絞り込み結果と照らし合わせて決めた）。

1. ✅ DONE → 出荷場（今日の分だけ読む）／📚 REFERENCE は出さない／🤖 AI → AIラボ
2. ⏳ WAITING → 待ち
3. 実行日が今日以前 → 今日やる、明日以降 → 予定あり
4. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
5. それ以外（📥 INBOX・日付なしの 🕰 SOMEDAY）→ 倉庫
6. プロジェクト は DB_プロジェクト（進行中の数）

DB_タスク管理の「今どこ」の式を変えたら `index.html` の `laneOf` も合わせる。

## 読むDB・書き換えるもの

- 読む：DB_タスク管理（未完了＋今日の済み）、DB_プロジェクト、DB_診断レポート（最新12回）、DB_運用ログ（最新40件）、DB_目標、🗄 データベース ページと各DB（開いたときに最新100行）
- 書く
  - DB_タスク管理の、読み込んだ行の「ステータス」「実行日」「AIアクション」「NEXT」（運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）
  - 開いたページの本文：チェック項目の付け外し（その1行だけ置き換え。同じ文が2つあれば書き換えない）と書き足し（既存の本文は消さない）
  - DB_タスク管理への新しい行（「✎」）
- ほかのDBのプロパティは読むだけ。パスワードらしい列は伏せる
