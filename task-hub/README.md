# 今どこ

Notion の私用タスク運用（GTD＋AIリサーチ）を1画面ずつで回すアプリ（claude.ai のアーティファクト）。
いちばん使う **AIリサーチの選別とやり取り**を中心に、タスクが濾過されていく流れ・仕分け・診断と運用ログ・すべてのDBをまとめ、本文は Notion と同じ書き方で直接編集できる。

- 公開先：[今どこ](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは、claude.ai の中では Notion 連携（MCP）、Cloudflare版では Notion API（Worker が中継）で入る。下の「2つの動かし方」
- 一覧は左右スワイプで頁送り（1頁の件数は画面の高さから自動で決める）。本文のエディタだけは中で縦に動く

## 画面

ホームは「今日」。下のタブは 今日・流れ・AI・仕分け・もっと（読む・買う・ニュース・運用・DB）の5つ。右下の＋で新しく入れる。

### 行の操作（どの一覧でも）

- タップ：ページを開く
- 右にスワイプ：✓ 済み／左にスワイプ：明日へ（済みの行は次にやるへ戻す）。どちらも取り消しできる
- 長押し：日付・状態・AIをすぐ変えるシート。ここと ページの下の「削除」（2回押し）で Notion のゴミ箱へ。5秒は「取り消す」で戻せる
- 右の日付を押しても同じシート
- 一覧の一番上で下に引っぱると更新。右上の↻でも
- PC：「/」で検索、「n」で新しく入れる

### 社内コンペ（2026/11/03）で直したこと

はじめて使う人・毎日使う人・片手のスマホ・情シス/品質・Notion運用者の5つの目で全画面を点検し、次を直した：タップ領域を40px以上に（○・日付・小ボタン・アイコン）／PWAで上の安全領域にヘッダーがかぶるのを直す／読み込めないときは「全部終わり」と区別して「もう一度」／更新に失敗したら前のデータの時刻を出す／作業中（▶ DOING）を一番上と「いま やっている」に／ヒーローの○でそのまま済み／新しく入れるときに「今日やる」／引っぱって更新／オフラインでも開ける（Cloudflare版・サービスワーカー）／長押しで文字選択が出ない／右下の＋が最後の行を隠さない

### 検索

上の虫めがね（PCは「/」キー）でタスク全体を探す。名前・次の一歩・分類タグで、読み込み済みはその場で、済みや古い資料も Notion に聞いて足す（スペース区切りで全部を含むもの）。すべて／未完了／済み／資料で絞れて、行の日付から日付・状態も変えられる

### 運用マップとの関係

- 使い方の要約は 2026/11/01 時点の Notion運用マップから作った固定の図。運用マップ本体の最終更新と変更履歴の新しい3件だけは開くたびに読む（Cloudflare版はインテグレーションが運用マップのページに接続されていれば）
- 買い物の品（親タスクのある子タスク。かいものアプリが作る）は、運用マップ 11/01 のとおり今どこには出さない

### 🧊 俯瞰（立体）

下のタブ「俯瞰」。未完了のタスク全体を立体の柱で見る。横＝流れの段（収集・AI・次にやる・予定・今日・待ち・いつか。段の色）、奥行き＝ジャンル／場所／重さ／滞留から選ぶ、高さ＝件数／重さの合計／古さ（平均の日数）から選ぶ。ドラッグで回す・傾ける、柱を押すとその中身が下に並ぶ（そこからスワイプ・長押しもできる）。何も選んでいないときは、いちばん高い柱3つと、2週間以上動いていない件数を出す。canvas に自前で描いていて外部の部品は使わない（`app/over.js`）。

### ⏭ 次にやる：見方で分ける

流れ → 次にやる（リスト表示）の上に見方のタブ。**滞留**（最後に動いてから 3日以内／1週間／2週間／1か月／それ以上）・**ジャンル**（分類タグ）・**場所**（枠）・**重さ**（S 5分〜XL 半日以上）・**つながり**（🎯 目標／📁 プロジェクト／単発）・**準備**（一歩あり／🔍✅ 調べ終わった／一歩なし）。グループのチップを押すとそのグループだけに絞れ、見方ごとに決め方のヒントが出る。グループの見出しに「全部 今日に」「全部 いつかへ」「全部 明日に」「全部 AIと分解」（見方とグループで変わる。2回押しで確定）。

### 🏠 節約（2027/3 まで、家の必要なものだけ）

下のタブ「節約」。DB_タスク管理の「買い物の区分」（🏠 家財／🧴 消耗品／🎮 娯楽）と「価格」を使う。上に「あと◯日・家財の残り・封印中・今月買った」と今月の家財の予算バー（タップで予算と解除日を変える。値は DB_アプリ「今どこ」の本文「⚙️ 今どこの設定」に保存）。

- 🏠 家財：買ってよいもの。○ で「買った」（✅ DONE・実行日＝今日）になり今月の予算に数える。「＋ 家財を足す」（名前・価格・次の一歩）
- 🎮 封印：自分の欲しいもの。「欲しいものを封印」で いつか＋実行日＝解除日 に入る。見るだけ・足すだけ。解除日を過ぎると ○ が出て、買う・手放すを決める
- 区分なし：BUY の買い物で区分が空のもの。チップで振り分け（娯楽 にすると いつか＋解除日）
- 今月：今月買った家財・消耗品と合計
- 行の長押し／▾ の「買い物」チップでも区分を変えられる。提案（コンシェルジュ）に「区分がまだ」「予算超え」「解除日」が出る。💡 タスクの提案も区分の振り分けを提案する
- AI タブは「もっと」の中へ（AI の番はホームの提案バーと「もっと」の印で分かる）

### 📱 iPhone のウィジェット（Scriptable）

`/widget/` を iPhone で開くと手順が出る。無料アプリ Scriptable に `public/widget/imadoko-widget.js` を入れると、ホーム画面（小・中・大）とロック画面（丸・四角・1行）に「今日の残り・遅れ・済みの輪・まず これ」が出る。中・大では行の ○ で済み、→ で明日にずらせる（Safari で `/w/act` が開いて結果を出し、「元に戻す」もある）。合言葉は初回にアプリ内で実行したときに聞き、iPhone の Keychain にだけ保存。15分ごとに更新、つながらないときは前回の内容を出す。

- Worker：`GET /api/widget`（合言葉つき）が今日の一覧と、行ごとの署名つき操作 URL を返す。署名は合言葉から作った HMAC（その日と翌日まで有効）なので、合言葉は URL に出ない
- `#open=<id>` で開くとそのタスクのページが開く（ウィジェットの行をタップしたとき）
- `imadoko-widget.scriptable` は build.mjs が js から作る（Scriptable で開くとそのまま取り込める）

### 💡 AIからの提案

毎朝 7:36 の定期実行「💡 タスクの提案」（正本は DB_スキルの同名ページ）が、タスク・目標・プロジェクト・前夜のジャーナル・診断を見て、既存タスクの整理（📅 日付・🗂 整理・🧹 手放す）と新タスク（🎯 目標の一歩・🆕 新タスク）を DB_AI提案 に最大7件置く。上の 💡 を押すと提案シートの一番上に「AIからの提案」が出て、「採用」でその場で操作（日付・状態の変更、タスク作成）を実行し行を ✅ 採用 に、「見送り」で ⏭ 見送り に（14日は同じ提案を繰り返さない）。「💡 今すぐ提案してもらう」は `/api/run` に `{"which":"suggest"}` を送り、`SUGGEST_ROUTINE_ID` / `SUGGEST_ROUTINE_TOKEN` の定期実行を起動する（設定は下の「今すぐ実行」と同じ手順）。

### ▶ 今すぐ実行

AIタブ右上の「次の定時処理」カードの「▶ 今すぐ実行」（誤タップよけに2回押し）で、毎時を待たずに「Notion AIリサーチ定時処理」を1回動かす。数分で反映するので、終わったら「↻」。定期実行は最短1時間おきなので、急ぎはこのボタンで補う（1時間に30回まで）。

- Cloudflare版：Worker の `/api/run` が claude.ai の定期実行の API トリガー（`/fire`）を叩く。定期実行の ID は `wrangler.toml` の `ROUTINE_ID`、トークンは secret の `ROUTINE_TOKEN`
- アーティファクト版：claude.ai の定期実行の一覧（https://claude.ai/code/routines ）を開くので、そこで「Run now」
- 設定（1回だけ）：https://claude.ai/code/routines で「Notion AIリサーチ定時処理」を開く → 編集 → Trigger の「＋」→「API」→「Generate token」でトークン（`sk-ant-oat01-…`、1回しか表示されない）をコピー → Cloudflare の Worker `imadoko` の「設定」→「変数とシークレット」に **シークレット** `ROUTINE_TOKEN` として追加。トークンはその定期実行を起動することしかできない。止めたいときは同じ画面で「Delete token」
- 祝日に押しても、定時処理の決まりで何もせずに終わる

### 提案

上の電球ボタン（流れでは上の帯）で、今の状態から次の一手を大事な順に出す：遅れ・今日の詰め込みすぎ・今日が空・AIの返事待ち・収集箱のたまり・次の一歩の空欄・止まっている次にやる・長い待ち・在庫切れ・今日の買い物・週末のいつか見直し・診断の次の一手。提案の中のボタンでそのまま日付や状態を変えられる。電球の数字は急ぎの提案の数

## GTDの段の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出す（今日・予定は DB_タスク管理の「今どこ」と同じ規則）。

1. ✅ DONE → 済み（実行日が今日のものを読む）／📚 REFERENCE → 資料（最近40件）
2. 🤖 AI → AI（あなたの番・AIの番は AIアクションで分ける。AIアクションの付いた行は状態を問わず AI タブに出る）
3. ⏳ WAITING → 待ち／🕰 SOMEDAY → いつか
4. 実行日が今日以前 → 今日、明日以降 → 予定
5. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
6. それ以外（📥 INBOX）→ 収集

段の規則を変えたら `index.html` の `stageOf` も合わせる。いつかへ動かすと実行日は外す（見直し日なしのルール）。

## 2つの動かし方

| | アーティファクト版（MCP） | Cloudflare版（Notion API） |
| --- | --- | --- |
| 開き方 | claude.ai のアーティファクト（[今どこ](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)）を開く | 自分の `workers.dev` のURLを開く（ホーム画面に追加するとアプリのように使える） |
| Notion への入り方 | 見ている人の claude.ai の Notion 連携（MCP）。トークン・合言葉・サーバーなし | Notion のインテグレーションのトークン（Cloudflare の秘密の値）。開くときは合言葉 |
| 準備 | なし（初回に「Notion を使ってよいか」の確認が出たら許可） | 下の「セットアップ」 |
| 読み書きできる範囲 | 自分の Notion アカウントで見えるもの全部 | インテグレーションを接続したページ・DBだけ |

画面は同じ1枚（`public/index.html`）。開いた場所で自動で切り替わる：`/api/ping` に Worker が答えれば Cloudflare版、claude.ai の中なら MCP、どちらでもなければ見本データ。
Worker は画面が MCP に出していた4つの道具（fetch・query・update・create）を Notion API に置き換え、MCP と同じ形で返す（`src/worker.js`）。

- 本文は Notion API の Markdown（`GET/PATCH /v1/pages/:id/markdown`、`markdown_version: v2`＝MCP と同じ Notion-flavored Markdown、`Notion-Version: 2026-03-11`）で読み、`update_content`（old_str→new_str）で変わった所だけ置き換える
- データソース・プロパティは `Notion-Version: 2025-09-03`
- 子ページ・データベースを消す全体の置き換え（allow_deleting_content）は Worker が受け付けない。タスクの「削除」は Notion のゴミ箱へ移す（`in_trash`・一度に10件まで）だけで、完全な削除はしない。「取り消す」は `notion-restore-pages` で戻す
- Notion API は計算式の値を返す（MCP は返さない）が、画面は今までどおりステータスと実行日から段を出す

### しくみ（Cloudflare版）

```
iPhone・PC（ブラウザ／ホーム画面） ──合言葉──▶ Cloudflare Worker ──トークン──▶ Notion API
                                              （画面の配信＋中継）
```

- 画面（index.html）と sw.js は `scripts/build.mjs` が `src/bundle.js` に同梱し、Worker の中から `Cache-Control: no-store` で配る（CDN の古いキャッシュで前の画面に戻らないため）。`/api/version` で今の配信番号（`X-Build` と同じ）が見える。`src/bundle.js` は生成物だがコミットする
- Notion のトークンは **Cloudflare 側の秘密の値にだけ**置く。スマホやブラウザ、社内PCには残らない
- 合言葉（APP_KEY・16文字以上）は端末のブラウザにだけ保存される。違うと 401 で、画面が入れ直しを聞く
- Cloudflare Workers の無料枠で動く

## セットアップ（Cloudflare版・PCのブラウザだけでできる）

### 1. Notion：インテグレーションを作る

1. https://www.notion.so/profile/integrations で「新しいインテグレーション」→ 種類：内部、名前：今どこ
2. 機能は「コンテンツを読み取る」「コンテンツを更新」「コンテンツを挿入」だけON（コメント・ユーザー情報はOFF）
3. シークレット（`ntn_…`）をコピーしておく（Notionのページには貼らない）
4. Notion で次に「•••」→「接続」→「今どこ」を追加する
   - **DB_タスク管理**・**DB_プロジェクト**・**DB_診断レポート**・**DB_運用ログ**・**DB_目標**（流れ・AI・仕分け・記録に要る）
   - **DB_Daily**（買う タブの在庫・補充に要る）・**DB_ニュース**（ニュース タブに要る）
   - DBタブで全DBを見るなら **🗄 データベース** のページ（中のDBにまとめて届く）。ただしアカウントなど見せたくないDBにも届くので、要るDBだけ個別に接続してもよい（接続していないDBは「接続されていません」と出るだけ）
   - ME などのさらに上のページには接続しない

### 2. Cloudflare：Worker を作る

1. https://dash.cloudflare.com に無料登録（個人のメールアドレスで）
2. 「Workers & Pages」→「作成」→「Gitリポジトリをインポート」→ GitHub の `my-apps` を選ぶ
3. 設定
   - プロジェクト名：`imadoko`
   - ルートディレクトリ：`task-hub`
   - ビルドコマンド：空欄／デプロイコマンド：`npx wrangler deploy`
4. デプロイ後、Worker の「設定」→「変数とシークレット」で **シークレット**を2つ追加して再デプロイ
   - `NOTION_TOKEN`：手順1でコピーした `ntn_…`
   - `APP_KEY`：合言葉（16文字以上。パスワードマネージャーで作ると楽）
   - （任意）`ROUTINE_TOKEN`：「▶ 今すぐ実行」用。上の「今すぐ実行」の設定を見る
   - （任意）`SUGGEST_ROUTINE_TOKEN`：「💡 今すぐ提案してもらう」用。定期実行「💡 タスクの提案」の API トリガーのトークン。ID は wrangler.toml の `SUGGEST_ROUTINE_ID`
5. `https://imadoko.<あなたのサブドメイン>.workers.dev` を開き、合言葉を入れて表示されたら完了

> 10/27：Worker `imadoko` は Claude の作業環境から `npx wrangler deploy` で公開済み（https://imadoko.roranosuke2525.workers.dev）。残りは手順4のシークレット2つだけ。GitHub との連携（push で自動デプロイ）はまだつないでいないので、更新は Claude に「デプロイして」と頼むか、手順2-2〜3でつなぐ。

以後、このフォルダを GitHub で更新すると自動で再デプロイされる。

### 3. iPhone：ホーム画面に追加

1. Safari で上のURLを開き、合言葉を入れる
2. 共有ボタン →「ホーム画面に追加」

### よくあるエラー

| 表示 | 原因 |
| --- | --- |
| 合言葉が違います | APP_KEY と違う。入れ直す |
| インテグレーションが接続されていません | 手順1-4 の接続忘れ（そのDB・ページだけ） |
| Notion のトークンが正しくありません | NOTION_TOKEN の貼り間違い |
| Worker の設定が足りません | シークレット2つが未設定、または APP_KEY が16文字未満 |
| 機能がありません | 手順1-2 の「読み取り・更新・挿入」がOFF |

## 開発

```sh
npm test                  # Worker のテスト（Notion は偽物に差し替え：test/fake-notion.mjs）
node scripts/build.mjs    # app/ の部品をつないで public/index.html を作る
npx wrangler dev          # ローカルで起動（.dev.vars に NOTION_TOKEN と APP_KEY を書く）
```

- `app/`：画面の部品（head.html・settings.js・data.js・editor.js・views.js・page.js・boot.js）。直したら build して `public/index.html` をコミットする
- `src/worker.js`：Notion API の中継
- `public/`：配る画面・manifest・アイコン
