# 今どこ線

Notion のタスク・診断・目標・すべてのDBを、**鉄道の路線図と発車標**で体系的に見て操作するアプリ（claude.ai のアーティファクト）。
タスクの「今どこ」（DB_タスク管理の計算式の6区分）が駅、タスクが列車。

- 公開先：[今どこ線](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- スクロールなし。一覧・本文は左右スワイプで頁をめくる（1頁の件数は画面の高さから自動で決める）

## 画面

| タブ | 中身 | 動き |
| --- | --- | --- |
| 路線図 | 今どこ本線（倉庫→次にやる→今日やる→済み）、予定線（予定あり）、AI線、待ち線、PJ線。駅の丸の大きさ＝件数。駅をタップすると下の **発車標** にその駅のタスク | 列車が線路を行き来する／選んだ駅が脈打つ／遅れがあると今日やるに「遅延」／乗り換えると点が駅から駅へ走る |
| 運行状況 | 最新の診断（判定→平常運転／遅れ気味、次の一手）、ゲージ（今日の到着率・遅延・待ち最長・自分の番）、診断の推移（流入・完了・今日やる完了率）、運行記録（DB_運用ログ） | ゲージと数字が伸びる／棒が伸び線が引かれる |
| 行き先 | DB_目標を終着駅に、紐づくプロジェクトをそこへ向かう路線に。路線の駅＝子タスク、列車の位置＝進み具合 | 列車が進み具合の位置まで走る |
| 全線図 | 🗄 データベース ページの節＝路線、DB＝駅。路線→駅→発車標（行の一覧）→乗車券（行の中身） | 各路線を列車が往復 |

- 上の電光掲示（運行情報）：遅延・到着数・待ちの最長・AIの自分の番・最新の診断・最新の運行記録が流れる
- 発車標：種別＝重さ（S普通・M快速・L急行・XL特急）、行先＝タスク名（長いと流れる）、時刻＝遅延日数・予定日・停車日数、番線＝枠。行はパタパタと表示
- 乗車券（タスク・行を開いたとき）：乗り換えボタン（今日やる・明日・週末・待ち・保留・資料・AIに調べて・済み）、本文（スワイプでめくる・チェック項目の✓・トグル）、項目、書く（やることに足す／メモ／次の一手）
- 右上「✎」：新しいタスク（臨時列車）を倉庫・次にやる・今日・明日から発車

## 「今どこ」の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出し直す（ME の各ビューの絞り込み結果と照らし合わせて決めた）。

1. ✅ DONE → 済み（今日の分だけ読む）／📚 REFERENCE は出さない／🤖 AI → AI駅
2. ⏳ WAITING → 待ち
3. 実行日が今日以前 → 今日やる、明日以降 → 予定あり
4. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
5. それ以外（📥 INBOX・日付なしの 🕰 SOMEDAY）→ 倉庫
6. プロジェクト は DB_プロジェクト（進行中の数）

DB_タスク管理の「今どこ」の式を変えたら `index.html` の `laneOf` も合わせる。

## 読むDB・書き換えるもの

- 読む：DB_タスク管理（未完了＋今日の済み）、DB_プロジェクト、DB_診断レポート（最新12回）、DB_運用ログ（最新40件）、DB_目標、🗄 データベース ページと各DB（開いたときに最新100行）
- 書く
  - DB_タスク管理の、読み込んだ行の「ステータス」「実行日」「AIアクション」「NEXT」（運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）
  - 開いたページの本文：チェック項目の付け外し（その1行だけ置き換え。同じ文が2つあれば書き換えない）と書き足し（既存の本文は消さない）
  - DB_タスク管理への新しい行（「✎」）
- ほかのDBのプロパティは読むだけ。パスワードらしい列は伏せる

## 公開

`index.html` をそのままアーティファクトとして公開する。capabilities：

```json
{"mcp": {"servers": [{"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page", "notion-create-pages"]}]}}
```

Notion 連携がないところ（ブラウザで直接開くなど）では、（例）の付いた見本で動く。
