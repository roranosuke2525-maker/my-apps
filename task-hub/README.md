# 今どこクエスト

Notion のタスク・診断・目標・すべてのDBを、**ドラクエ3風のレトロRPG**で体系的に見て操作するアプリ（claude.ai のアーティファクト）。
タスクの「今どこ」（DB_タスク管理の計算式の6区分）が町の建物、今日やるタスクが町の外のまもの。

- 公開先：[今どこクエスト](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- スクロールなし。一覧・本文・まもののむれは左右スワイプで頁をめくる（1頁の件数は画面の高さから自動で決める）

## 画面

黒地に白枠のウィンドウ、▶カーソル、文字送りのメッセージ。下のコマンド：まち／たたかう／つよさ／ふくろ／かきこむ／さいしん。

| 画面 | 中身 |
| --- | --- |
| まち | 町の地図（ドット絵）。建物＝今どこ。建物をタップすると勇者が歩いて入り、住人の台詞とタスクの一覧。名前を選ぶとコマンド（きょう たたかう・あしたへ・しゅうまつへ・たおした（済み）・やどやで まつ・ねむらせる（1かげつ）・しょこへ（資料）・けんじゃに たのむ（🔍）・しらべる（本文）） |
| たたかう | 今日やるタスク＝まもの（4ひきずつ、スワイプで次のむれ）。遅れは赤く震える「いかり」。たたかう＝済み（倒れる・EXP）、にげる＝明日、じゅもん＝🔍・待ち・寝かせる・週末 |
| つよさ | 今日倒した数・残り・いかり・経験値・自分の番、HP（今日やる完了率）・MP、おうさまの おことば（最新の診断）、ぼうけんの きろく（診断の推移）、できごと（DB_運用ログ） |
| ふくろ | 🗄 データベース ページの節＝しゅるい、DB＝どうぐ。どうぐ→行の一覧（検索）→行の中身 |

| 建物 | 今どこ・中身 |
| --- | --- |
| おしろ | 目標（おうさまの願い）とプロジェクト（クエスト・完成度バー） |
| さかば | 倉庫（INBOX） |
| ギルド | 次にやる（古い順） |
| とけいとう | 予定あり（日付順） |
| けんじゃのとう | AI（💭・🔍✅は自分の番） |
| やどや | 待ち |
| きょうかい | 済み（今日の分）と ぼうけんのしょ（DB_運用ログ） |
| まちのそと | 今日やる → たたかう画面へ |

- 経験値は重さで決まる：S10・M20・L40・XL80（空はM扱い）
- 詳細（タスク・行を開いたとき）：コマンド、ほんぶん（スワイプでめくる・チェック項目・トグル）、つよさ（項目）、かきこむ（やることに足す／メモ／つぎのいって）
- 「かきこむ」：新しいタスク（さかば・ギルド・きょう たたかう・あしたへ のどこへ入れるか選ぶ）

## 「今どこ」の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出し直す（ME の各ビューの絞り込み結果と照らし合わせて決めた）。

1. ✅ DONE → きょうかい（今日の分だけ読む）／📚 REFERENCE は出さない／🤖 AI → けんじゃのとう
2. ⏳ WAITING → 待ち
3. 実行日が今日以前 → 今日やる、明日以降 → 予定あり
4. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
5. それ以外（📥 INBOX・日付なしの 🕰 SOMEDAY）→ 倉庫
6. プロジェクト は DB_プロジェクト（進行中の数）

DB_タスク管理の「今どこ」の式を変えたら `index.html` の `laneOf` も合わせる。

## 読むDB・書き換えるもの

- 読む：DB_タスク管理（未完了＋今日の済み）、DB_プロジェクト、DB_診断レポート（最新12回）、DB_運用ログ（最新40件）、DB_目標、🗄 データベース ページと各DB（開いたときに最新100行）
- 書く
  - DB_タスク管理の、読み込んだ行の「ステータス」「実行日」「AIアクション」「NEXT」（運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）
  - 開いたページの本文：チェック項目の付け外し（その1行だけ置き換え。同じ文が2つあれば書き換えない）と書き足し（既存の本文は消さない）
  - DB_タスク管理への新しい行（「かきこむ」）
- ほかのDBのプロパティは読むだけ。パスワードらしい列は伏せる

## 公開

`index.html` をそのままアーティファクトとして公開する。capabilities：

```json
{"mcp": {"servers": [{"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page", "notion-create-pages"]}]}}
```

Notion 連携がないところ（ブラウザで直接開くなど）では、（例）の付いた見本で動く。
