# 今どこ工場

Notion のタスク・診断・目標・すべてのDBを、**工場の生産ライン**で体系的に見て操作するアプリ（claude.ai のアーティファクト）。
タスクの「今どこ」（DB_タスク管理の計算式の6区分）が工程、タスクが箱。別案集（下）の「工場」案を本番にしたもの。

- 公開先：[今どこ工場](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- スクロールなし。一覧・本文は左右スワイプで頁をめくる（1頁の件数は画面の高さから自動で決める）

## 画面

| タブ | 中身 | 動き |
| --- | --- | --- |
| ライン | 受入（倉庫）→仕分け（次にやる）→予定棚（予定あり）→加工（今日やる）→出荷（済み）、保留棚（待ち）、AIロボ（AI）、組立（プロジェクト）。機械の上の箱の山＝件数。工程をタップすると下の **アンドン** にその工程のタスク | ベルトが動き箱が流れる／歯車が回る（遅れがあると加工が遅くなる、保留棚は止まる）／遅れは加工のランプが赤く点滅し、赤い箱になる／AIロボの腕が動く／工程を移すと箱が工程から工程へ飛ぶ |
| 生産管理 | 最新の診断（判定→正常稼働／要改善、改善＝次の一手）、計器（出荷率・遅れ・在庫＝倉庫・自分の番）、生産の推移（入荷＝流入・出荷＝完了・今日やる完了率）、作業日報（DB_運用ログ） | 計器と数字が伸びる／棒が伸び線が引かれる |
| 受注 | DB_目標を受注、紐づくプロジェクトを製造ロットに。ロットのベルト上の箱の位置＝完成度 | ベルトが動き、箱が完成度の位置まで進む |
| 倉庫 | 🗄 データベース ページの節＝棚、DB＝品目。棚→品目→アンドン（行の一覧）→作業伝票（行の中身） | 棚の前をフォークリフトが行き来 |

- 上の電光掲示（構内放送）：遅れ・出荷数・保留の最長・AIの自分の番・最新の診断・最新の作業日報が流れる
- アンドン：品種＝重さ（S小物・M中物・L大物・XL特大）、品名＝タスク名（長いと流れる）、納期・遅れ日数・滞留日数、ライン＝枠。行はパタパタと表示
- 作業伝票（タスク・行を開いたとき）：移動ボタン（加工へ・予定棚（明日／週末）・保留棚へ・寝かせる・資料室へ・AIロボへ・出荷）、本文（スワイプでめくる・チェック項目の✓・トグル）、項目、書く（やることに足す／メモ／次の作業）
- 右上「✎」：新規入荷（受入・仕分け・加工・予定棚（明日）のどこに入れるか選ぶ）

## 「今どこ」の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出し直す（ME の各ビューの絞り込み結果と照らし合わせて決めた）。

1. ✅ DONE → 出荷（今日の分だけ読む）／📚 REFERENCE は出さない／🤖 AI → AIロボ
2. ⏳ WAITING → 待ち
3. 実行日が今日以前 → 今日やる、明日以降 → 予定あり
4. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
5. それ以外（📥 INBOX・日付なしの 🕰 SOMEDAY）→ 倉庫
6. プロジェクト は DB_プロジェクト（進行中の数）

DB_タスク管理の「今どこ」の式を変えたら `index.html` の `laneOf` も合わせる。

## 読むDB・書き換えるもの

- 読む：DB_タスク管理（未完了＋今日の済み）、DB_プロジェクト、DB_診断レポート（最新12回）、DB_運用ログ（最新40件）、DB_目標、🗄 データベース ページと各DB（開いたときに最新100行）
- 書く
  - DB_タスク管理の、読み込んだ行の「ステータス」「実行日」「AIアクション」「NEXT」（運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）
  - 開いたページの本文：チェック項目の付け外し（その1行だけ置き換え。同じ文が2つあれば書き換えない）と書き足し（既存の本文は消さない）
  - DB_タスク管理への新しい行（「✎」）
- ほかのDBのプロパティは読むだけ。パスワードらしい列は伏せる

## 公開

`index.html` をそのままアーティファクトとして公開する。capabilities：

```json
{"mcp": {"servers": [{"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page", "notion-create-pages"]}]}}
```

Notion 連携がないところ（ブラウザで直接開くなど）では、（例）の付いた見本で動く。
