# 今どこ

Notion の私用タスク運用（GTD＋AIリサーチ）を1画面ずつで回すアプリ（claude.ai のアーティファクト）。
いちばん使う **AIリサーチの選別とやり取り**を中心に、タスクが濾過されていく流れ・仕分け・診断と運用ログ・すべてのDBをまとめ、本文は Notion と同じ書き方で直接編集できる。

- 公開先：[今どこ](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- 一覧は左右スワイプで頁送り（1頁の件数は画面の高さから自動で決める）。本文のエディタだけは中で縦に動く

## 画面

| タブ | 中身 |
| --- | --- |
| 流れ | GTDの段（収集→AI→次にやる／予定／待ち→今日→済み、横にいつか・資料）を図で。線の上を件数に応じて点が流れる。段を押すと下にその一覧（リスト／ボード／表）。○を押すと済み（取り消しあり） |
| AI | あなたの番（💭 回答する・🔍✅ 判定する）／AIの番（🔍🔬💬）／依頼する。結論（⭐）や明確度・質問を一覧で先読み。次の定時処理の時刻つき |
| 仕分け | 収集・判定待ち（🔍✅）・次にやる・待ち・いつか の山を1枚ずつ。→やる ←いつか ↑AIに調べて ↓資料（山ごとに少し違う）。取り消しあり |
| 記録 | 診断（完了率・完了/流入・判定と次の一手・推移のグラフ・各回）／運用ログ（イベントで絞る）／目標とプロジェクト（進み具合） |
| DB | 🗄 データベース ページの節ごとに全DB。開くと表・リスト・ボード（状態・選択の列でまとめる）と検索 |

### ページ（タスク・行を開いたとき）

- 名前・プロパティ（ステータス・AIアクション・実行日・次の一歩・枠・重さ・分類タグ）をその場で変更
- AIとのやり取りの帯
  - 💭：最新の「💬 最新のやり取り」の質問票を読み取り、選択肢のチェックと「💬 コメント」を書いて **回答してAIに返す（💬へ）**
  - 🔍✅：⭐ の結論を出し、行き先（やる・今日やる・資料・いつか・済んだ・返事待ち）を1タップ。メモを書いて 🔍再調査／🔬徹底調査／💬深掘り に戻せる（メモは本文に ✍️ のコールアウトで残す。いつかの理由は「## メモ」へ）
  - AIの番：印の付け替え・取り下げ
- 本文エディタ（Notion と同じ Markdown を読み書き）
  - 見出し・テキスト・ToDo・箇条書き・番号・トグル・引用・コールアウト・区切り線・コード・表（セル編集・行追加）・目次
  - 「/」でブロックを選ぶ、「# 」「- 」「[] 」「1. 」「> 」などの書き出し、Enter で分割、Backspace で結合、Tab で字下げ
  - 文字を選ぶと 太字・斜体・下線・取り消し線・コード・リンク・色
  - 複数行を貼ると Markdown として読む。⋮⋮ で移動・複製・削除・種類の変更
  - 保存は自動（1.2秒）。**変わった最上位ブロックの範囲だけ**を update_content で置き換えるので、触っていない所（メンション・データベース・段組みなど）はそのまま。Notion 側が先に変わっていたら保存せず知らせる
  - 段組み・同期ブロック・データベースなどは表示だけ（Notionで開くリンク）

## GTDの段の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出す（今日・予定は DB_タスク管理の「今どこ」と同じ規則）。

1. ✅ DONE → 済み（実行日が今日のものを読む）／📚 REFERENCE → 資料（最近40件）
2. 🤖 AI → AI（あなたの番・AIの番は AIアクションで分ける。AIアクションの付いた行は状態を問わず AI タブに出る）
3. ⏳ WAITING → 待ち／🕰 SOMEDAY → いつか
4. 実行日が今日以前 → 今日、明日以降 → 予定
5. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
6. それ以外（📥 INBOX）→ 収集

段の規則を変えたら `index.html` の `stageOf` も合わせる。いつかへ動かすと実行日は外す（見直し日なしのルール）。

## 読むDB・書き換えるもの

- 読む：DB_タスク管理（未完了＋今日の済み）、DB_プロジェクト、DB_診断レポート（最新12回）、DB_運用ログ（最新40件）、DB_目標、🗄 データベース ページと各DB（開いたときに最新100行）
- 書く
  - DB_タスク管理の、読み込んだ行の「ステータス」「実行日」「AIアクション」「NEXT」（運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）
  - 開いたページの本文：チェック項目の付け外し（その1行だけ置き換え。同じ文が2つあれば書き換えない）と書き足し（既存の本文は消さない）
  - DB_タスク管理への新しい行（右上の「＋」：収集箱へ／AIに頼む）
- ほかのDBのプロパティは読むだけ。パスワードらしい列は伏せる

