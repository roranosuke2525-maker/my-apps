# 今どこボード

Notion の **DB_タスク管理** を、計算式「今どこ」の6区分ごとの専用ビューで1画面に出すアプリ（claude.ai のアーティファクト）。
下のタブで 🤖 AI に預けている行と、🗄 データベース ページにある **すべてのDB**（回る球体から開く）も見られる。

- 公開先：[今どこボード](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- 基本はスクロールなし。入りきらない一覧は ‹ › か左右スワイプでページ送り（件数は画面の高さから自動で決める）

| 区分 | ビュー | できること |
| --- | --- | --- |
| ☀️ 1 今日やる | 今日の進み具合＋「いまやる」1枚＋枠順のチェックリスト（遅れは赤） | 完了・明日へ・日付なし |
| 📅 2 予定あり | 明日から2週間の帯（日ごとの件数）＋日付順の一覧。日をタップで絞る | 今日へ・日付なし など |
| 🔥 3 次にやる | 最終更新が古い順に1枚ずつ振り分け（左スワイプ＝あとで） | 今日／明日／週末／完了／待ち／保留／資料 |
| 📥 4 倉庫 | INBOX（日付なし）を分類タグで絞れる2列タイル。最近の100件 | NEXTへ・今日・AIに調べて など |
| ⏳ 5 待ち | WAITING を、最後に動いてからの日数が長い順にバー付きで | NEXTへ・完了 など |
| 🎯 6 プロジェクト | DB_プロジェクトのカード（進捗＝紐づくタスクのうち完了の割合・次の一歩）。ステータスで切替 | タップで残りの子タスク |
| 🤖 AI | ステータス＝🤖 AI を 💭回答待ち／🔍✅判定待ち／AIの番 で分ける | 採用・保留・資料・再調査 |
| 🌐 DB | 🗄 データベース ページのDBを球体に並べる。ドラッグで回す、セクションのボタンでその面へ回る、タップで正面に回して開く | 最新100行・絞り込み・行の中身（パスワードらしい列は伏せる） |

## 「今どこ」の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出し直す（ME の各ビューの絞り込み結果と照らし合わせて決めた）。

1. ✅ DONE・📚 REFERENCE は出さない／🤖 AI は AI タブへ
2. ⏳ WAITING → 5 待ち
3. 実行日が今日以前 → 1 今日やる、明日以降 → 2 予定あり
4. 日付なしの ⏭ NEXT・▶️ DOING → 3 次にやる
5. それ以外（📥 INBOX・日付なしの 🕰 SOMEDAY）→ 4 倉庫
6. 🎯 プロジェクト は DB_プロジェクトそのもの

DB_タスク管理の「今どこ」の式を変えたら `index.html` の `laneOf` も合わせる。

## 書き換えるもの

DB_タスク管理の、この画面で読み込んだ行の「ステータス」「実行日」「AIアクション」だけ（Notion 運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）。
ほかのDBは読むだけ。

## 公開

`index.html` をそのままアーティファクトとして公開する。capabilities：

```json
{"mcp": {"servers": [{"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page"]}]}}
```

Notion 連携がないところ（ブラウザで直接開くなど）では、（例）の付いたサンプルで動く。
