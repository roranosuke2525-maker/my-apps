# 今どこ♡ダイアリー

Notion のタスク・診断・目標・すべてのDBを、**恋愛アドベンチャー（ギャルゲー）風**に見て操作するアプリ（claude.ai のアーティファクト）。
タスクの「今どこ」（DB_タスク管理の計算式の6区分）を6人のヒロインが1つずつ受け持ち、タスクを済ませると担当の子の好感度が上がる。ヒロインは全員大人の設定。

- 公開先：[今どこ♡ダイアリー](https://claude.ai/artifact/1eDZLbLLp3d6F7Mr7nKQE9)
- Notion へは見ている人の claude.ai の Notion 連携（MCP）で入る。トークン・サーバーなし
- スクロールなし。一覧・本文は左右スワイプで頁をめくる（1頁の件数は画面の高さから自動で決める）
- ヒロイン・背景はすべて SVG で描いている（瞬き・呼吸・表情：通常／笑顔／むくれ／照れ／驚き／眠い）

## 画面

下のメニュー：みんな／デート／思い出／スマホ／メモを渡す／更新。

| 画面 | 中身 |
| --- | --- |
| みんな | 6人のカード（件数・好感度Lv・遅れ／あなたの番などの札・今の表情）と、いちばん声をかけたい子からのメッセージ |
| 会話（カードをタップ） | 場所の背景と立ち絵、セリフ（1文字ずつ）、タスクが選択肢。選ぶとヒロインがひとこと言い、答え（済ませたよ♡・今日いっしょにやろ・明日にしよ・週末にしよ・ナギと待つ・また今度ね・本棚にしまう・アイに調べてもらう…）を選ぶ。済ませるとハートが舞い、好感度＋重さ（S10・M20・L40・XL80） |
| デート | ヒナタ（今日やる）との会話へ直行 |
| 思い出 | 今日のときめき（今日やる完了率のハート）、数字、シオリからの手紙（最新の診断）、ふたりの記録（診断の推移）・約束（目標とプロジェクト）・日記（DB_運用ログ）・今日の思い出（今日済ませたもの） |
| スマホ | 🗄 データベース ページの節＝フォルダ、DB＝アプリ。アプリ→行の一覧（検索）→行の中身 |

| ヒロイン | 今どこ | 場所 |
| --- | --- | --- |
| ヒナタ（幼なじみ） | 今日やる | 公園 |
| シオリ（図書館司書） | 次にやる | 図書館 |
| ツムギ（時計店の店員・ツンデレ） | 予定あり | 時計店 |
| モモ（雑貨屋の後輩） | 倉庫 | 雑貨屋 |
| ナギ（カフェ店員・眠そう） | 待ち | カフェ |
| アイ（研究所のAI助手） | AI | ラボ |

- 機嫌：遅れがあるとヒナタがむくれる、次にやるが古いとシオリが困り顔、倉庫が15件を超えるとモモが驚く、AIの「あなたの番」があるとアイが照れる
- 好感度はこの端末のブラウザに覚える（Notion には書かない）
- 中身（タスク・行を開いたとき）：答えのボタン、中身（スワイプでめくる・チェック項目・トグル）、項目、書く（やることに足す／メモ／次の一歩）
- 「メモを渡す」：新しいタスク（モモ＝倉庫・シオリ＝次にやる・ヒナタ＝今日・ツムギ＝明日 のだれに渡すか選ぶ）

## 「今どこ」の出し方

Notion の MCP は計算式の値を返さないので、アプリの中でステータスと実行日から出し直す（ME の各ビューの絞り込み結果と照らし合わせて決めた）。

1. ✅ DONE → 思い出（今日の分だけ読む）／📚 REFERENCE は出さない／🤖 AI → アイ
2. ⏳ WAITING → 待ち
3. 実行日が今日以前 → 今日やる、明日以降 → 予定あり
4. 日付なしの ⏭ NEXT・▶️ DOING → 次にやる
5. それ以外（📥 INBOX・日付なしの 🕰 SOMEDAY）→ 倉庫
6. プロジェクト は DB_プロジェクト（進行中の数）

DB_タスク管理の「今どこ」の式を変えたら `index.html` の `laneOf` も合わせる。

## 読むDB・書き換えるもの

- 読む：DB_タスク管理（未完了＋今日の済み）、DB_プロジェクト、DB_診断レポート（最新12回）、DB_運用ログ（最新40件）、DB_目標、🗄 データベース ページと各DB（開いたときに最新100行）
- 書く
  - DB_タスク管理の、読み込んだ行の「ステータス」「実行日」「AIアクション」「NEXT」（運用マップの判定ルールどおり：待ち＝実行日を外す、保留＝見直し日を1か月後）
  - 開いたページの本文：チェック項目の付け外し（その1行だけ置き換え。同じ文が2つあれば書き換えない）と書き足し（既存の本文は消さない）
  - DB_タスク管理への新しい行（「メモを渡す」）
- ほかのDBのプロパティは読むだけ。パスワードらしい列は伏せる

## 公開

`index.html` をそのままアーティファクトとして公開する。capabilities：

```json
{"mcp": {"servers": [{"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page", "notion-create-pages"]}]}}
```

Notion 連携がないところ（ブラウザで直接開くなど）では、（例）の付いた見本で動く。
