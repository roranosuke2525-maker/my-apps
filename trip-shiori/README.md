# 旅のしおり（PWA）

Notion のタスクページ「11/12～11/14までのディズニーの旅行用のアプリ作成」の **☑️ ToDo** を、
スマホで日付ごとに見て・チェックして・足せるWebアプリ。ホーム画面に追加するとアプリのように使える。

| 画面 | 中身 |
| --- | --- |
| 日付のタブ（11/12・11/13・11/14） | ToDo の「11/12（木）」などの下の予定を時刻順の線で表示。今日のタブが最初に開き、次の予定に「つぎ」。お店・ホテル・駅には **地図** ボタン（Googleマップで開く・APIキー不要）。予定を足せる（例：`16:00 ベビーセンター`） |
| マップ | 行きたい場所（アトラクション・レストランなど）を足すと、ランド／シーの**自作の模式図**（エリアの位置関係だけ。公式マップではない）に番号のピンが立つ。予定に出てくるお店も赤いピンで出る。ピンを押すと下の一覧へ、一覧の **地図** で Google マップを開く。足した場所は Notion の ToDo の「📍 行きたい場所」に入る |
| 準備 | 日付以外のまとまり（事前準備・ToDo など）をチェックリストで表示。入れ子（ポーチ → サングラス）もそのまま。各まとまりに足せる。**まとまりを足す**（例：👕 服装、🛍 買い物）と Notion の ToDo の最後に入る |

- 丸を押すと済み／戻す。文字を **長押し** で直せる
- 園内で電波が弱くても開ける（最後に読んだしおりを端末に保存）。圏外で押したチェック・足した項目は端末に残し、電波が戻ったら順番に Notion へ送る（下の帯に「未送信n件」）
- 未送信がある間は Notion から読み直さない（端末の変更を上書きしないため）

## Notion のページの書き方

```
## ☑️ ToDo          ← 「ToDo」を含む見出しから次の見出しまでを読む（見出しが無ければページ全体）
- [ ] 11/12（木）    ← 「月/日」で始まるチェック＝日付のタブ
  - [ ] 7:00　車で自宅を出発      ← 先頭の「時:分」が時刻
  - [ ] 13:30　レストラン北斎     ← お店・ホテル・駅などの名前があれば地図ボタン
- [ ] 事前準備       ← それ以外のチェック＝準備タブのまとまり
  - [ ] ポーチ
    - [ ] サングラス
```

- 地図で探す場所：かっこの中が場所ならそれ（`ルームサービス（東京ディズニーランドホテル）`）、「〜駅」はその駅、ほかは「チェックイン」などを除いた文。後ろに `MAP_AREA`（舞浜）を足して探す。地図ボタンが出ない行に出したいときは文のどこかに 📍 を付ける。文にリンクを貼ると「リンク」ボタンも出る
- しおりに出さないもの：`HIDE_GROUPS`（wrangler.toml）に書いた書き出しのまとまり、済みにした1行だけのチェック（「〇〇を決める」など）、ToDo 見出しより後ろのもの

## マップの場所の見つけ方

- `public/places.js` の施設名の一覧（エリアごと）と照らし合わせる。一部だけでもよい（「カリブ」→ カリブの海賊）
- 一覧に無いものは「場所がわからないもの」に出る。後ろに（エリア名）を付けるとそのエリアに出る。例）`ポップコーン（トゥーンタウン）`
- 施設が増えた・名前が変わったときは `public/places.js` の `PLACE_LIST` に足す

## しくみ

```
iPhone（ホーム画面のアプリ） ──合言葉──▶ Cloudflare Worker ──トークン──▶ Notion API
```

- Notion のトークンは **Cloudflare 側の秘密の値にだけ**置く。スマホやブラウザには残らない
- Worker が書き換えるのは、`PAGE_ID` のページの ToDo の下にあるチェックボックスだけ（済み・文字・下に足す）と、ToDo の最後へのまとまりの追加だけ。それ以外のページ・ブロックは拒否。消す機能は無い
- アプリを開くには合言葉（APP_KEY）が必要。合言葉は端末のブラウザにだけ保存される
- Cloudflare Workers の無料枠で動く
- 次の旅行では `wrangler.toml` の `PAGE_ID`・`TITLE`・`TRIP_YEAR`・`MAP_AREA` を変えるだけで使い回せる

## セットアップ（PCのブラウザだけでできる）

### 1. Notion：インテグレーションを作る

1. https://www.notion.so/profile/integrations で「新しいインテグレーション」→ 種類：内部、名前：旅のしおり
2. 機能は「コンテンツを読み取る」「コンテンツを更新」「コンテンツを挿入」だけON（コメント・ユーザー情報はOFF）
3. シークレット（`ntn_…`）をコピーしておく（Notionのページには貼らない）
4. Notion で **11/12～11/14までのディズニーの旅行用のアプリ作成** のページを開き、右上「•••」→「接続」→「旅のしおり」を追加
   - DB_タスク管理 や ME などの親には接続しない（このページだけ）

### 2. Cloudflare：Worker を作る

1. https://dash.cloudflare.com （習慣チェックと同じアカウントでよい）
2. 「Workers & Pages」→「作成」→「Gitリポジトリをインポート」→ GitHub の `my-apps` を選ぶ
3. 設定
   - プロジェクト名：`trip-shiori`
   - ルートディレクトリ：`trip-shiori`
   - ビルドコマンド：空欄／デプロイコマンド：`npx wrangler deploy`
4. デプロイ後、Worker の「設定」→「変数とシークレット」で **シークレット**を2つ追加して再デプロイ
   - `NOTION_TOKEN`：手順1でコピーした `ntn_…`
   - `APP_KEY`：合言葉（16文字以上）
5. `https://trip-shiori.<あなたのサブドメイン>.workers.dev` が表示されたら完了

### 3. iPhone：ホーム画面に追加

1. Safari で上のURLを開き、合言葉を入れる
2. 共有ボタン →「ホーム画面に追加」
3. 一度開いたあと機内モードにして、ホーム画面から開けるか試す
4. 一緒に行く家族のスマホにも同じURLと合言葉で入れれば、同じしおりを見てチェックできる

## よくあるエラー

| 表示 | 原因 |
| --- | --- |
| 合言葉が違います | APP_KEY と違う。下の「合言葉を消す」から入れ直す |
| インテグレーションが接続されていません | 手順1-4 の接続忘れ |
| Notion のトークンが正しくありません | NOTION_TOKEN の貼り間違い |
| Worker の設定が足りません | シークレット2つが未設定、または APP_KEY が16文字未満 |
| 日付のタブが出ない | ToDo の下のチェックが「11/12」のように「月/日」で始まっていない |
| 未送信n件 のまま | 電波が無い。電波のある所で右上の ↻ を押す |

## 開発

```sh
npm install
npm test               # Worker のテスト（Notion は偽物に差し替え）
npx wrangler dev       # ローカルで起動（.dev.vars に NOTION_TOKEN と APP_KEY を書く）
python3 scripts/make-icons.py   # アイコン画像の生成
```

- `src/worker.js`：Notion API の中継（API バージョン 2025-09-03、ブロックの読み書き）
- `public/`：画面（HTML/CSS/JS、サービスワーカー、アイコン）。画面ファイルを直したら `public/sw.js` の `CACHE` の番号を上げる
