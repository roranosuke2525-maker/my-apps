# 仕様書の型（Claude Code に渡す1枚）

アイデア出し・見た目の案は Gemini などで先に済ませ、決まったことだけをこの形で書く。
空欄は「おまかせ」でよい（Claude Code が無難な方を選び、最後に「決めたこと」で知らせる）。
新しいアプリは `アプリ名/SPEC.md` に、直しは Notion のタスク本文にこの形で書いて渡す。
