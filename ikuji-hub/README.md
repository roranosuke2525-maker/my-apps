# 育児ハブ（PWA）

Notion にちらばっている育児まわりの情報と、Google カレンダーの育児の予定を1か所で見るスマホ向けアプリ。
見た目は夜空・お城・金の星の「魔法の国」風（特定の会社のキャラクターやロゴは使っていない）。

| 下のタブ | 中身 |
| --- | --- |
| たな | 奏輔の月齢、60日以内の予定（Notion の日付＋カレンダー）、★ピン留め、棚（離乳食・ミルク／からだ・医療／お世話・ねんね／あそび・本／保育園・おでかけ／手続き・お金／そのほか）、さがす、育児タスクの追加 |
| ごはん | ミルクの分量の計算（アイクレオ標準・1mlあたり 0.127g）、離乳食・ミルクの棚 |
| ねんね | 今月のねんね（寝る場所・寝かしつけ・担当・寝る／起きる時刻・夜中に起きる回数・昼寝・うまくいったこと・困っていること・本文）を入れて Notion に記録。前の月の内容が下書きに入る。下に月齢ごとの推移 |
| せっしゅ | カレンダーの健診・接種の予定、これからの予防接種と健診（一般的な目安・誕生日から時期を計算） |
| ほいくえん | 妻の復職（2027/1/19）までの日数、保育園の予定（カレンダーと Notion）、保育園のやること・メモ |

項目を押すと下から詳しく開く。育児タスクは「完了にする」「NEXT にする」、すべて「Notion で開く」。

## 読む／書くもの

| つなぎ先 | 読む | 書く |
| --- | --- | --- |
| DB_タスク管理 | 分類タグ CHILD で、✅ DONE 以外（📚 REFERENCE は「しらべた」） | ステータスだけ（この画面で読んだ CHILD のタスクに限る）、INBOX への追加 |
| DB_childcare memo | 全件（分類タグで棚に振り分け、Star ☆ をピン留め） | なし |
| 支援の申請・給付 | 全件（申請状況・期限・助成内容） | なし |
| DB_ねんね記録 | 全件と、選択肢（寝る場所・寝かしつけ・担当）の設定、今月の行の本文 | 今月の月齢の行（あれば書き換え、なければ1行足す）。選択肢にない値・おかしな時刻や回数は書かない。本文は読み込んだ本文から変わったときだけ置き換え、表・画像など文字だけでない本文は書き換えない（< > は全角にする） |
| Google カレンダー | 今日から180日。名前か説明に育児の言葉（奏輔・検診・健診・接種・保育園・慣らし・離乳食・小児科など）を含む予定だけを画面に渡す（アーティファクト版は祝日以外の見えているカレンダー、Cloudflare版は非公開アドレスを入れたカレンダー） | なし |

- 子どもの名前・誕生日・妻の復職日は、アーティファクト版は `src/mcp-api.js` の `CHILD`、Cloudflare版は `wrangler.toml` の `CHILD_NAME`・`CHILD_BIRTH`・`BACK_TO_WORK`（「大事な日」と 10/26 の棚卸しより）
- 棚の振り分けは `public/app.js` の `SHELVES`。育児メモは分類タグで、ほかは名前の言葉で決まる
- ミルクの係数は育児メモ「🍼 ミルクの分量」の表、予防接種の目安は育児メモ「予防接種」と REFERENCE「奏輔のこれからの予防接種（1歳〜）」から `public/app.js` に書いてある
- 保育園の予定は、カレンダーに「保育園」「慣らし」「入園」を含む名前で入れると並ぶ

## 2つの動かし方

| | アーティファクト版（MCP） | Cloudflare版 |
| --- | --- | --- |
| 開き方 | claude.ai のアーティファクト（[育児ハブ](https://claude.ai/artifact/5jnJmPxWaknK94WbPDKMi4)）を開く | 自分の `workers.dev` のURLを開き、合言葉を入れる。ホーム画面に追加できる |
| Notion への入り方 | 見ている人の claude.ai の Notion 連携。トークン・合言葉なし | Notion のインテグレーションのトークン（Cloudflare の秘密の値） |
| カレンダー | 見ている人の claude.ai の Google カレンダー連携 | Google カレンダーの「iCal 形式の非公開アドレス」（Cloudflare の秘密の値）。繰り返しの予定は最初の1回だけ |
| 準備 | なし（初回に Notion・Google カレンダーの利用を許可） | 下の「セットアップ（Cloudflare版）」 |

画面（`public/`）は同じ。アーティファクト版の /api は `src/mcp-api.js` が画面の中で、Cloudflare版は `src/worker.js` が答える（返事の形は同じ）。

## アーティファクト版

claude.ai のアーティファクト（[育児ハブ](https://claude.ai/artifact/5jnJmPxWaknK94WbPDKMi4)）を開く。
Notion・Google カレンダーへは見ている人の claude.ai の連携（MCP）で入るので、トークン・サーバー・社内PCへの保存はない。初回にそれぞれ「使ってよいか」の確認が出たら許可する。カレンダーを許可しなくても、Notion の部分は使える。

```sh
npm test                          # /api（src/mcp-api.js）を偽の連携で確かめる
node scripts/build-artifact.mjs   # dist/artifact.html を作る（公開は Claude に「アーティファクトを更新して」）
```

公開するときは capabilities に次を宣言する。

```json
{"mcp": {"servers": [
  {"server": "Notion", "tools": ["notion-fetch", "notion-query-data-sources", "notion-update-page", "notion-create-pages"]},
  {"server": "Google Calendar", "tools": ["list_calendars", "list_events"]}
]}}
```

## Cloudflare版

```
iPhone（ホーム画面のアプリ） ──合言葉──▶ Cloudflare Worker ──トークン──▶ Notion API
                                          （画面の配信＋中継）  ──非公開アドレス──▶ Google カレンダー（iCal）
```

- Notion のトークンとカレンダーの非公開アドレスは **Cloudflare 側の秘密の値にだけ**置く。スマホやブラウザ、社内PCには残らない
- Worker が書き換えるのは次だけ（それ以外は拒否）
  - DB_タスク管理：分類タグ CHILD のタスクのステータス（📚 REFERENCE は変えない）と、INBOX・CHILD での追加
  - DB_ねんね記録：月齢の行の書き換え・追加と、その本文（文字だけの本文のとき）
- アプリを開くには合言葉（APP_KEY）が必要。合言葉は端末のブラウザにだけ保存される
- Cloudflare Workers の無料枠で動く

### セットアップ（PCのブラウザだけでできる）

#### 1. Notion：インテグレーションを作る

1. https://www.notion.so/profile/integrations で「新しいインテグレーション」→ 種類：内部、名前：育児ハブ
2. 機能は「コンテンツを読み取る」「コンテンツを更新」「コンテンツを挿入」だけON（コメント・ユーザー情報はOFF）
3. シークレット（`ntn_…`）をコピーしておく（Notion のページには貼らない）
4. Notion で次の4つのDBを開き、右上「•••」→「接続」→「育児ハブ」を追加
   - **DB_タスク管理**（Worker が CHILD のタスクだけに絞る）
   - **DB_childcare memo**
   - **支援の申請・給付**
   - **DB_ねんね記録**
   - ME・データベースなどの親ページには接続しない
   - データソースIDは `wrangler.toml` の `[vars]` に書いてある

#### 2. Google カレンダー：非公開アドレスをコピーする（なくてもよい）

1. PC の Google カレンダー →「設定」→ 左の「マイカレンダーの設定」で、育児の予定が入るカレンダー（自分・家族など）を選ぶ
2. 「カレンダーの統合」の **iCal 形式の非公開アドレス** をコピー（このアドレスを知っている人は予定を全部読めるので、どこにも貼らない）
3. 妻のカレンダーの非公開アドレスは、妻のアカウントでしか出せない。必要なら妻にコピーしてもらう
4. 複数あるときは改行かカンマで区切って並べる

#### 3. Cloudflare：Worker を作る

1. https://dash.cloudflare.com （habit-check と同じアカウントでよい）
2. 「Workers & Pages」→「作成」→「Gitリポジトリをインポート」→ GitHub の `my-apps` を選ぶ
3. 設定
   - プロジェクト名：`ikuji-hub`
   - ルートディレクトリ：`ikuji-hub`
   - ビルドコマンド：空欄／デプロイコマンド：`npx wrangler deploy`
4. デプロイ後、Worker の「設定」→「変数とシークレット」で **シークレット**を追加して再デプロイ
   - `NOTION_TOKEN`：手順1でコピーした `ntn_…`
   - `APP_KEY`：合言葉（16文字以上。パスワードマネージャーで作ると楽。habit-check とは別にする）
   - `CALENDAR_ICS_URLS`：手順2の非公開アドレス（なければ入れない。せっしゅ・ほいくえんのカレンダーの欄が「読めませんでした」になるだけ）
5. `https://ikuji-hub.<あなたのサブドメイン>.workers.dev` が表示されたら完了

以後、このフォルダを GitHub で更新すると自動で再デプロイされる。

#### 4. iPhone：ホーム画面に追加

1. Safari で上のURLを開き、合言葉を入れる
2. 共有ボタン →「ホーム画面に追加」

### よくあるエラー

| 表示 | 原因 |
| --- | --- |
| 合言葉が違います | APP_KEY と違う。たなの一番下「合言葉を消す」から入れ直す |
| インテグレーションが接続されていません | 手順1-4 の接続忘れ（4つのDBすべて） |
| Notion のトークンが正しくありません | NOTION_TOKEN の貼り間違い |
| Worker の設定が足りません | シークレットが未設定、または APP_KEY が16文字未満 |
| カレンダーの設定がありません | CALENDAR_ICS_URLS が未設定（なくても Notion の部分は使える） |
| カレンダーを読めませんでした | 非公開アドレスの貼り間違い。アドレスをリセットした場合は貼り直す |

### 開発

```sh
npm install
npm test               # Worker とアーティファクト版 /api のテスト（Notion・カレンダーは偽物に差し替え）
npx wrangler dev       # ローカルで起動（.dev.vars に NOTION_TOKEN・APP_KEY・CALENDAR_ICS_URLS を書く）
```
