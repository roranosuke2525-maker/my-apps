# かいもの（PWA）

買い物だけを1つにまとめたアプリ。Notion の **買い物リスト**（DB_タスク管理の分類タグ BUY のタスク）と **在庫**（DB_Daily）をスマホで回し、切れそうな在庫を **iPhone に通知** する。
今どこ（task-hub）の「買う」タブと同じ Notion を読み書きするので、どちらで操作しても同じ結果になる。

| 下のメニュー | 中身 |
| --- | --- |
| 📝 リスト | リストを上のチップで切り替え（スーパー・ドラッグストア…、＋で新しいリスト）。入力欄に「牛乳、卵、パン」と入れると一度に入る。打ちかけると、前に入れた品目・在庫・定番から候補が出て、タップで入る。入力欄が空のときは「📦 切れそう」「よく買う」を並べる。品目は **売り場順**（野菜→肉・魚→卵・乳製品→…）に自動で並べるか、入れた順。タップでかごへ（チェック）、⋯で直す・消す。「かごの○品をリストから消す」「買い物おわり（済みにする）」。📦補充 のチップは在庫から作った補充タスク（✓で済み） |
| 📦 補充 | DB_Daily を切れる日の近い順に。残りのゲージ、切れている／7日以内／リスト済み の数。「🛒 リストへ」で補充タスクを作る（DB_Daily の補充ボタンと同じ形）、「✓／補充した」で済みにして最終補充日を今日に。切れそうな品を **まとめてリストへ**、＋ 在庫を登録 |
| 🔔 通知 | 在庫アラートのオン・オフ、知らせる時刻（5〜22時）、切れる何日前から、買い物リストの残りも知らせるか。「いま試す」で今の内容をすぐ送る |

- 切れそうな在庫（補充タスクがまだないもの）は、リスト画面の上の帯・タブの赤いバッジ・ホーム画面のアイコンのバッジにも出る
- 品目の書き込みは端末に順番待ちで貯め、**圏外でもチェックや追加ができる**（電波が戻ると順に Notion へ送る。右上に「圏外・○件待ち」）。画面と最後に読んだリストもキャッシュするので、お店の中で開き直しても見られる
- 「牛乳 2」「卵×1パック」の数は名前の横にバッジで出る
- 売り場の当て方は `public/aisle.js` の言葉の一覧（足したい言葉はここへ）
- 本文の ToDo は**いちばん上の段**だけを品目として扱う（入れ子の ToDo は Notion で見る）。見出し（#〜###）は「入れた順」のときの区切りになる
- 「📦 切れそう」の候補をタップすると、今のリストに品目として入る（補充タスクにはならない）。最終補充日まで付けたいときは 📦 補充 の「🛒 リストへ」か「✓」を使う

## しくみ

```
iPhone（ホーム画面のアプリ） ──合言葉──▶ Cloudflare Worker ──トークン──▶ Notion API
            ▲                              │ 毎時0分（cron）
            └──── 在庫アラート（Web Push）◀─┘ 時刻を選んだ端末にだけ・1日1回
```

- Notion のトークンは **Cloudflare 側の秘密の値にだけ**置く。スマホやブラウザ、社内PCには残らない
- Worker が書き換えるのは次だけ（それ以外のページ・ブロックは拒否）
  - DB_タスク管理の、分類タグ BUY か 補充対象つきのタスク：ステータス（済みにする）・本文の ToDo（足す・チェック・名前・消す）
  - DB_タスク管理への買い物リスト・補充タスクの追加（BUY・⏭ NEXT・重さ S）
  - DB_Daily への在庫の追加
- 通知の宛先は Apple・Google・Mozilla・Microsoft の通知サービスだけ受け付ける。登録は Cloudflare の KV（`SUBS`）に置く。通知の鍵（VAPID）は Worker がはじめて使うときに作って同じ KV にしまう（人が秘密鍵を扱わない）
- Cloudflare Workers の無料枠で動く（cron・KV も無料枠内）

## セットアップ（PCのブラウザだけでできる）

### 1. Notion：インテグレーションを作る

1. https://www.notion.so/profile/integrations で「新しいインテグレーション」→ 種類：内部、名前：かいもの
2. 機能は「コンテンツを読み取る」「コンテンツを更新」「コンテンツを挿入」だけON（コメント・ユーザー情報はOFF）
3. シークレット（`ntn_…`）をコピーしておく（Notionのページには貼らない）
4. Notion で次の2つを開き、右上「•••」→「接続」→「かいもの」を追加する
   - **DB_タスク管理**（買い物リスト・補充タスク）
   - **DB_Daily**（在庫）。つながっていないと、補充対象の関連が読めない
   - （任意）**DB_プレイヤー**：作るタスクにプレイヤーを付けて EXP を数えるなら。つながっていなければプレイヤーなしで作る
   - ME・データベースなどの親ページには接続しない

### 2. Cloudflare：Worker を公開する

通知の登録先（KV `kaimono-subs`）は作成済みで、ID は `wrangler.toml` に書いてある。

1. https://dash.cloudflare.com →「Workers & Pages」→「作成」→「Gitリポジトリをインポート」→ GitHub の `my-apps` を選ぶ
2. 設定
   - プロジェクト名：`kaimono`
   - ルートディレクトリ：`kaimono`
   - ビルドコマンド：空欄／デプロイコマンド：`npx wrangler deploy`
3. デプロイ後、Worker の「設定」→「変数とシークレット」で **シークレット**を2つ追加して再デプロイ
   - `NOTION_TOKEN`：手順1でコピーした `ntn_…`
   - `APP_KEY`：合言葉（16文字以上。パスワードマネージャーで作ると楽）
4. `https://kaimono.roranosuke2525.workers.dev` を開き、合言葉を入れて表示されたら完了

（Claude に「かいものをデプロイして」と頼んでもよい。その場合は手順3のシークレットだけ自分で入れる）

### 3. iPhone：ホーム画面に追加して通知をオンにする

1. Safari で上のURLを開き、合言葉を入れる
2. 共有ボタン →「ホーム画面に追加」
3. **ホーム画面のアイコンから**開き直し、🔔 通知 →「通知をオンにする」→ 許可（iOS 16.4 以上。Safari のタブのままでは通知を使えない）
4. 「いま試す」で通知が届けば完了

### よくあるエラー

| 表示 | 原因 |
| --- | --- |
| 合言葉が違います | APP_KEY と違う。入れ直す |
| インテグレーションが接続されていません | 手順1-4 の接続忘れ |
| Notion のトークンが正しくありません | NOTION_TOKEN の貼り間違い |
| Worker の設定が足りません | シークレット2つが未設定、または APP_KEY が16文字未満 |
| 通知が拒否されています | iPhone の 設定 → 通知 → かいもの で許可 |
| 通知の登録が切れていました | 通知をオンにし直す（アプリを消して入れ直したときなど） |

## 開発

```sh
npm test                     # Worker（Notion・通知サービスは偽物：test/worker.test.mjs）と売り場の当て方のテスト
npx wrangler dev             # ローカルで起動（.dev.vars に NOTION_TOKEN と APP_KEY を書く）
python3 scripts/make-icons.py  # アイコンを作り直す
```

- `src/worker.js`：Notion API の中継・毎時のアラート
- `src/webpush.js`：Web Push の暗号化（aes128gcm）と VAPID の署名。ライブラリなし（WebCrypto）
- `public/`：画面（`app.js`・`aisle.js`・`style.css`）・service worker（キャッシュと通知の受け取り）・manifest・アイコン
- 画面のファイルを変えたら `public/sw.js` の `CACHE` の版を上げる
