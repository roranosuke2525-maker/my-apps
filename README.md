# my-apps

- [habit-check](habit-check/) — Notion の習慣チェックをスマホから入力するWebアプリ（PWA）
- [ikuji-hub](ikuji-hub/) — Notion の育児まわり（タスク・メモ・申請）を棚ごとに探せるWebアプリ（PWA）
- [task-hub](task-hub/) — 今どこ：AIリサーチの回答・判定を中心に、GTDの流れ・仕分け・診断・全DBをまとめ、本文をNotionと同じ書き方で編集できるタスクアプリ（アーティファクト）
- [shiori](shiori/) — しおり：付箋のページの写真と Kindle のハイライトを Notion の読書メモに集め、読後は読書メーター・NotebookLM へ渡す読書ノート（アーティファクト）
